# Android UI / UX 设计规范 v1.0

## 1. 产品目标和优先级

**产品主张**：一句话开始听，让科普资料成为可探索、可持续陪伴的私人知识音频馆。

**三条首要用户任务**：
1. **直接听**：用户说或输入“今天想听火星 / 想听轻松有趣的”，高可信时自动选择本地实际存在的节目、开始播放，并将其他相关节目放入候选队列；低可信时先展示备选。
2. **专心听**：屏幕关闭、切换应用、耳机控制、调整倍速、记忆进度；需要时看文稿或配图，无需时保持安静界面。
3. **找回来**：通过剧集式节目档案、专题分类、关键词、全文/段落搜索、收藏和历史找到多年积累的声音。

**设计原则**：收听优先；AI 可解释但不抢戏；本地优先；尊重阅读和夜间场景；任何没有证据的时间对齐不得伪造；强关联未确认时不表现为已确认；无网络时优雅降级。

## 2. 信息架构（IA）

主底栏：**听什么**／**节目库**／**我的**。

- 听什么（首页）：自然语言搜索入口、快捷情境标签、继续收听、最近推荐、上次听过。
- 节目库：全部节目、专题/标签、搜索、过滤、排序、节目详情；未来支持段落命中。
- 我的：历史、收藏、播放队列、媒体库状态、设置。
- 二级独立页面：智能搜索（输入/结果）、节目详情、全屏播放器、媒体库导入与诊断、设置。
- 全局组件：**迷你播放器**始终在底栏上方（无节目时不显示）；全屏播放器是可关闭的页面，不是第四个底栏标签。
- 后台播放由 Media3 `MediaSessionService` 管理，不受屏幕切换影响。

```text
App
├── 听什么（Home）
│   ├── 智能输入 → 正在理解 → 搜索结果/自动播放
│   └── 继续收听 → 全屏播放器
├── 节目库（Library）
│   ├── 标签/分类/筛选/离线搜索
│   ├── 节目详情 → 播放/收藏/文稿/配图
│   └── 搜索结果（节目命中 / 段落命中）
├── 我的（Mine）
│   ├── 收藏 / 历史 / 队列
│   └── 设置 → 本地资料管理 / AI 与隐私 / 外观与播放
└── 全局迷你播放器 → 全屏播放器
    ├── 画面（封面/轮播配图）
    ├── 文稿（普通全文/时间同步）
    └── 播放队列（Bottom Sheet）
```

## 3. 视觉规范

品牌方向：「深空静谧 Quiet Cosmic」。不是科技炫光或聊天机器人界面。深色优先、浅色可切换，遵循 Material 3 交互约定。

| Token | 暗色推荐值 | 用途 |
|---|---|---|
| `background` | `#101827` | 页面背景 |
| `surface` | `#1C2940` | 卡片与底部播放条 |
| `surfaceElevated` | `#253550` | 弹层/突出卡片 |
| `primary` | `#97BBFF` | 主按钮、选中态 |
| `secondary` | `#CEB6FF` | AI、注释、星空氛围 |
| `accent` | `#E7C68C` | 少量温暖点缀 |
| `onBackground` | `#F3F6FD` | 主文字 |
| `muted` | `#B3C2D9` | 辅助文字 |

- 尺寸：横向页边距 16–20 dp；组件间距遵循 4 / 8 / 12 / 16 / 24 dp；卡片圆角 16–20 dp；表单 12–16 dp。
- 文字：页标题 24 sp，模块标题 18–20 sp，正文 16 sp，说明 13–14 sp；支持系统字号放大。
- 最小交互区域 48×48 dp；TalkBack 标签完整；不能仅依赖颜色区分状态。
- 动效：页面过渡 180–250 ms；按钮反馈 100–180 ms；尊重减少动画设置；播放画面不持续闪烁。
- 图像：优先使用本地节目配图，不随意下载网络图片；缺图时采用简洁渐变占位图。
- 夜间场景：默认柔和高对比、无自动弹窗、无强制动态背景；支持系统主题与手动切换。

## 4. 页面清单与内容层级

### P00 首次启动 / 媒体库导入

- 品牌标识与一句话简介。
- 主操作「选择本地媒体库文件夹」；使用 Android SAF 目录授权。
- 识别清单版本、导入包、节目数、媒体可访问性、索引版本；明确「只读取，不移动原件」。
- 导入进度：读取清单 → 校验 → 建立本地数据库 → 媒体定位 → 完成；失败可重试，避免半导入显示为成功。
- AI 设置为可选跳过，不要求登录。API 密钥由用户输入，不在源码中内置共享密钥。
- 资料包就绪但未复制音频时，区分「节目已建档」和「本地音频可播放」。

### P01 听什么：首页

自上而下：
1. 顶栏「星河回响」+ 一句简短文案 + 设置/导入状态入口（状态异常时才醒目）。
2. **主输入卡片**：「今天想听些什么？」自然语言输入框；主操作「开始听」；次操作「只查看结果」；语音输入图标预留，未实现时不放可点击的空按钮。
3. 快捷建议 Chips：「天文故事」「轻松有趣」「半小时以内」「继续上次」。点击快捷建议填入搜索条件并明确操作，避免无意立即播放。
4. 「继续收听」大卡：封面、节目名、上次进度、剩余时长、恢复播放按钮；无历史时不占空白。
5. 「为你发现」：基于已有元数据本地推荐 3–5 期，标注理由；不能声称未实际执行的“AI已分析今天心情”。
6. 迷你播放器与底栏。

### P02 智能搜索页（输入与结果是同一路由不同状态）

- 顶部搜索框，保留原始查询；支持最近查询和清除。
- 搜索状态依次显示「理解需求」「检索节目」「排列候选」，避免假进度百分比。
- 在线模式：查询 → IntentParser → Embedding → 本地混合检索/硬约束 → 排序；LLM 不能生成不存在的节目 ID。
- 搜索意图分成 `PLAY_NOW`、`SEARCH_ONLY`、`CONTINUE`、`BUILD_QUEUE`，以输入动作和明确 UI 按钮为准；不因模型不确定而擅自播放。
- `PLAY_NOW` 且匹配达到可信门槛、媒体本地可播放：自动播放 Top-1、生成后续智能队列、弹轻量提示「已为你找到……」。可信门槛通过测试集校准，**不把向量相似度直接解释成概率**。
- `SEARCH_ONLY` / 匹配不确定：先展示候选，不自动播放。
- 结果卡：封面、标题、时长、主题、为何匹配、可播放标识；节目级命中显示「整期相关」，段落级命中显示「文稿第 N 段涉及……」及简短摘录。
- 若未建立时间对齐，段落命中**不显示虚构播放时间**，也不提供假“跳到第 18:20”按钮。
- 结果项点击进入节目详情；明确的「播放」按钮才执行播放；长按/更多菜单可「下一期播放」「加入队列」「收藏」。
- 网络失败：显示「AI 搜索暂不可用」，保留输入，允许跳转本地关键词检索；不自动发送文稿全文到 API。

### P03 节目库

- 顶部「节目库」+ 本地搜索框。
- 标签区：「全部」「专题」「最近导入」「未听」「已听」；内容区域可切换节目列表/卡片网格。
- 筛选条件：主题、时长、难度、含文稿、含配图、可播放、已听状态；排序：标题、导入时间、时长、最近播放。
- 节目单项：封面缩略图、标题、描述一行、时长、进度、最多两个标签；右上角收藏操作与更多菜单。
- 目录无媒体文件但有档案时显示「文件未在手机上」，可重新关联，不把问题藏起来。
- 本地普通搜索无网络仍可用；若未来加入离线全文索引，可在页内扩展「全文」过滤。

### P04 节目详情（剧集档案）

- 顶部封面/主配图、节目标题、副标题（有则显示）、时长、主题、知识难度、风格、来源信息（如果可证实）。
- 主操作「播放本期」/「继续播放」；辅操作「下一期播放」「加入队列」「收藏」。
- 内容摘要；章节/段落目录（只有可靠结构时显示）；文稿预览；配图缩略图横滑；相关节目。
- 展示「资料完整度」：音频可用、文稿可用、配图数量、时间同步支持情况；不要向普通用户直接展示内部 UUID 或哈希。
- 未确认或缺失的关联只在诊断页显示待审，不假装已经确认。

### P05 全屏播放器（主打页面）

顶部：下拉/返回收起，节目标题，收藏和更多菜单。

中部提供双模式 Segment：`画面` | `文稿`。切换仅改变可视内容，不重启音频。

**画面模式**：默认展示当前封面；多张配图时可左右浏览，底部小字可见图片说明与页码。提供轮播开关：
- `手动`：用户左右翻页，播放进度不改变。
- `顺序轮播`：无时间轴时按固定间隔轮播，显式称为轮播，不声称与声音精确同步。
- `内容同步`：只有存在可靠图片—文本—音频时间对齐关系时才开放；来源置信度不足则降级。

**文稿模式**：初始支持全文正常滚动；如果 `TranscriptCue` 具有可靠起止时间，才高亮当前句并随播放滚动。用户手动滚动时暂停自动跟随，显示「回到当前播放位置」按钮；没有可靠时间对齐时只提供阅读，不虚构高亮和时间定位。

底部固定控件：当前时间 / 总时长 / 可拖动进度条；后退 15 秒、播放暂停、前进 30 秒；下一排：倍速、定时停止、播放队列、循环选项（按需）。

- 点击播放/暂停必须即时更新 UI，不等待页面网络请求。
- 更换配图模式、查看文稿和查看队列均不能停止播放。
- 记忆本期播放进度，节目自然结束时根据队列进入下一期。
- 通过耳机、蓝牙、锁屏及通知操作的状态与界面保持一致。
- 对大幅拖动和长时节目遵循 Media3 位置更新，不把进度写库频率设得过高。

### P06 播放队列（Bottom Sheet）

- 分组「正在播放」「接下来」「为你推荐的候选」；区分已经正式加入队列与仅供选择的相关推荐。
- 队列条目：缩略图、标题、时长、拖拽把手、删除操作。
- 支持重排、删除、播放下一期、全部清空；当前正在播放的节目不可被误当作普通待播项删除。
- 用户手工调整过的队列，不能因后台重新计算推荐而无声覆盖。
- 新的一次明确「开始听」可以创建新的智能收听会话；若会替换已有手工队列，需明确提示或提供保留入口。
- 播放到最后一期时停止或按明确设置的续播策略运行，不无条件无限推荐。

### P07 我的

分区：收藏、最近收听、已听/未听、我的播放队列、媒体库状态、设置。

默认突出能帮助继续收听的项目，不做社交、签到、排行榜、账号体系。

### P08 设置 / 媒体库诊断

- **媒体库**：当前授权目录、总节目数、可播放数、缺失音频数、上次导入时间、索引版本；「重新关联目录」「导入增量更新包」。
- **智能功能**：联网 AI 开关、API Key 配置、仅使用已建档内容、默认「开始听」行为、历史影响推荐的程度。
- **播放体验**：默认倍速、跳转秒数、续播策略、定时停止、是否跳过已听节目。
- **外观与无障碍**：深/浅/跟随系统、字体、动效、图片轮播。
- **隐私**：音频/文稿/图片/索引保存在本地；联网 AI 搜索可能向第三方 API 提交用户查询；默认不上传完整文稿。
- 删除/重建索引不应删除收藏、播放进度和用户手工队列。

## 5. 核心操作流程

### F1：一句话自动播放（最关键）

```text
首页输入需求 → 点击「开始听」
       ↓
校验有已导入媒体库？否 → 引导导入
       ↓是
网络与 API 可用？否 → 提供离线普通搜索，不假称智能分析
       ↓是
解析意图 → 生成查询向量 → 本地检索 → 硬约束过滤 → 综合排序
       ↓
最佳候选可靠、可播放、非歧义？
  ├─ 是 → 播放 Top-1 → 生成后续队列 → 展示轻量理由 → 可展开播放器
  └─ 否 → 展示候选与理由 → 用户决定播放哪一期
```

### F2：找到藏在节目中间的知识

```text
输入“火星表面的红色是怎么来的”
 → 段落级命中 → 显示所属期和命中文稿摘要
 → 点击结果 → 打开节目详情并定位/突出显示相应文字段落
 → 有可靠对齐：可以「从这一段播放」
 → 无可靠对齐：只能「播放整期」并定位阅读段落，不伪造音频起点
```

### F3：播放时看图

```text
播放页「画面」→ 封面 → 用户选「手动」/「顺序轮播」
 → 存在可靠时间锚点时允许「内容同步」
 → 图片切换与音频播放分离，切换播放页面不重启媒体
```

### F4：在节目库浏览与播放

```text
节目库 → 选主题/筛选 → 点节目卡进入详情
 → 播放 / 继续播放 / 播放下一期 / 加入队列
 → 全局迷你播放器始终可用
```

### F5：资料包增量更新

```text
设置 → 导入增量更新包 → 版本和身份检查
 → 显示新增/更新/待审/缺失统计 → 应用到本地数据库
 → 稳定 episode_id 对齐历史、收藏和进度
 → 原来的播放器会话不被不必要地重置
```

## 6. 全局交互规则

| 动作 | 行为 | 备注 |
|---|---|---|
| 点击节目卡空白区域 | 打开详情 | 避免意外开始播放 |
| 点击「开始听」 | 智能搜寻并尽可能自动播 | AI 不确定时展示备选 |
| 点击「只查看结果」 | 搜索但不自动播放 | 尊重探索意图 |
| 点击迷你播放器 | 展开全屏播放器 | 音频不中断 |
| 下滑全屏播放器 / 顶部收起 | 回到原页面 | 不暂停音频 |
| 点击文稿段落 | 有时间对齐才允许跳转到该时间 | 无对齐时只选中文稿 |
| 手动滚动文稿 | 暂停自动跟随，显示回位按钮 | 不改变播放进度 |
| 长按节目卡 / 更多菜单 | 收藏、加入队列、下一期播放 | 增强操作，不阻塞主路径 |
| 切换底部导航 | 保持搜索草稿、筛选状态与播放状态 | 避免重复输入 |
| 系统返回 | 先关闭弹层，再退二级页，最后回主页面 | 遵循系统预测性返回 |
| 没有网络 | 普通搜索与播放正常；AI 明示不可用 | 不伪装在线结果 |
| 节目文件缺失 | 解释原因、重新关联，不开始空播放 | 严禁悄悄跳到不相关节目 |

## 7. 状态设计与空态

- `LibraryState`: Unconfigured / Importing(progress & stage) / Ready / PartiallyAvailable / ImportFailed。
- `SmartSearchState`: Idle / Parsing / Retrieving / Ranking / AutoPlaying / Results / NoMatch / Offline / Error。
- `PlaybackState`: Idle / Buffering / Playing / Paused / Ended / MediaMissing / PlaybackError；以 Media3 实际状态为准。
- `TranscriptState`: Missing / PlainText / ApproximateAlignment / VerifiedAlignment；仅 VerifiedAlignment 默认自动逐句跟随，其他等级需要明确标记，不做虚假精度承诺。
- `ImageState`: NoImages / CoverOnly / Slideshow / TimedImages；不得把有顺序的图片误标为“精准同步”。

**空态文案示例**：
- 尚未导入：`把收藏多年的节目，带进星河回响。` 按钮「选择媒体库」。
- AI 离线：`当前无法使用在线智能搜索。你仍可以按标题和标签查找本地节目。` 按钮「使用离线搜索」。
- 无匹配：`还没有找到足够符合的节目。试试放宽时长或换个说法。` 按钮「查看接近的候选」。
- 无配图：`这一期暂时没有配图。` 继续显示主封面占位。
- 无时间对齐：`可阅读完整文稿，暂不支持随音频逐句滚动。`
- 文件缺失：`节目档案还在，但音频文件未找到。` 按钮「重新关联目录」。

- 页面只渲染 `UiState` 并发出 `UiAction`；ViewModel 处理意图；Repository 提供节目、文稿、图片与检索结果。
- Media3 `MediaSessionService` 是播放状态的唯一权威来源；ViewModel 订阅其状态，不另外维护“平行播放器”。
- 搜索上下文（原查询、筛选、候选结果）与播放会话分离，返回上一页不能丢失正在收听的队列。
- 迷你播放器放在 App 根级 `Scaffold`，全屏播放器和底部弹层按导航层级叠加。
- 入口使用稳定 `episode_id`；文件 URI 由资源层解析，不把物理路径硬塞到 UI。
- 首版手机竖屏优先；平板与横屏至少保证不裁剪内容，可后续采用 `NavigationSuiteScaffold`。
