# 开发规范

这份文档记录**踩过的坑**和由此形成的硬性规则。每条规则背后都有一次真实的错误。

---

## 一、UI 自动化与实机验证

### 1.1 禁止写死点击坐标

**规则**：任何 `adb shell input tap X Y` 的坐标，必须来自当次运行时的 UI 树（`uiautomator dump`）或截图测量，不允许凭记忆、凭上次的数值写死。

**做法**：
```powershell
adb shell uiautomator dump /sdcard/x.xml
# 按 text / content-desc 精确匹配，取 bounds 中心点
```

**为什么**：首页卡片位置会随内容（继续收听、最近在听的有无）上下浮动；播放器底部按钮位置随字幕/配图模式变化。写死的坐标点空、点到别的卡片、甚至点到别的 App，我都遇到过：
- 点「睡前」场景卡片点空，实际点到了搜索页的「睡前听」胶囊，白白跑了一轮测试；
- 手机停在 Bilibili，坐标照旧发送，点击落进了别人的 App。

**例外**：只用于「打开 App」「返回」这类与布局无关的系统按键（`KEYCODE_BACK`）可以不用坐标。

### 1.2 点击前先确认前台是自家 App

```powershell
adb shell "dumpsys window | grep mCurrentFocus"
```
不是 `io.github.jolewis.echoes` 就先 `am start` 拉起来。否则点击全部无效，还会污染别人的 App。

### 1.3 不要用缩放后的预览图推算坐标

预览图是 837 宽、真机是 1200 宽，按比例换算会偏 400–600 px。要用原图测量，或直接用 UI 树的 bounds。

### 1.4 `uiautomator dump` 在动画界面会失败

播放器有轮播动画时 `dump` 会报 `could not get idle state`。先暂停播放，或改用 `screencap` 截图判断。

## 二、状态与返回键

### 2.1 每加一个覆盖层，必须同步改三处

1. 渲染顺序（提前 `return` 的分支）
2. `BackHandler` 的 `enabled` 条件
3. `BackHandler` 的 `when` 分支

漏过三次（播放器、详情页、情景编辑页），每次表现都是「按返回没反应」。系列合集页又漏了一次——页面内部的二级状态没有自己的 `BackHandler`，一按直接退到上一级页面。

### 2.2 页面内部的层级要有自己的 BackHandler

在页面组件里注册 `BackHandler(enabled = 内部状态 != null) { 内部状态 = null }`。Compose 的 BackHandler 是后注册者优先，子组件能先于 Activity 拦截。

## 三、偏好与迁移

### 3.1 迁移版本号必须递增，且改完要验证

改代码时用 `scene_ver < N`，N 必须比设备上已存的值大。**改完要打印实际条件确认**：

```python
m = re.search(r'scene_ver", 1\) < \d+', s)
print(m.group(0))   # 确认真的改了
```

我用字符串替换改版本号，但之前另一处改动把 `getInt` 换成了 `intOf`，导致替换**静默不匹配**——代码看着改了，实际没生效，白测一轮。

### 3.2 prefs 读写不能想当然类型

`Profile.restore` 曾把所有数字按 Long 写回，而读取用 `getInt`，直接 `ClassCastException` 崩溃。现在统一走 `intOf()` / `longOf()` 容错。

## 四、数据

### 4.1 加工结果必须有独立备份

音频、配图是可再生的原始素材；**打标、简介、时间轴是不可再生的加工结果**。每跑完一批就快照到 `E:\2049备份\<日期>\`，带 SHA256 校验清单。

### 4.2 删除前先验证路径与备份

- 打印待删目录、确认内容；
- 确认备份里期数对得上（如 3218/3218）；
- 再删。

### 4.3 脚本的「已完成」判断要自动发现

批处理脚本靠手工维护「已完成目录」列表，漏写一个就导致**整批重复跑**（浪费 2 个 GPU 小时）。改成 `glob` 自动发现，并加重叠自检。

---

## 五、长任务

### 5.1 长时间任务一律放后台

超过 1 分钟的等待（转码、ASR、批量导入）必须 `Start-Process` 后台跑，立即返回「已启动 + 预计多久」，需要结果时再查。不要在对话里 `Start-Sleep` 干等。

### 5.2 后台任务要有可读的日志文件

写到固定路径（如 `E:\2049asr6\fade_result.txt`），下次直接读，不依赖对话历史。

---

## 六、服务器与资源

### 6.1 只用自己账户空间，只用真正空闲的卡

开跑前查 `nvidia-smi`，挑显存 <1.5 GB 且利用率 <15% 的卡；没有就等，不硬挤。

### 6.2 进程降优先级

`nice -n 10 ionice -c2 -n7`，线程数限制 4。别人要用 CPU 能优先拿到。

### 6.3 用完清理

上传的音频、临时转码文件，处理完就删；模型缓存保留（避免重复下载）。
